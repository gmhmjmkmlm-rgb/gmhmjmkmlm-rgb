## 🚀 मुख्य ओपन सोर्स प्रोजेक्ट्स

यहाँ कुछ प्रमुख इन्फ्रास्ट्रक्चर प्रोजेक्ट्स हैं जिन्हें मैंने डिज़ाइन किया है और जिनका रखरखाव करता हूँ:

### 1. `vortex-kv`
> Rust में विकसित उच्च-प्रदर्शन एम्बेडेड की-वैल्यू स्टोरेज इंजन।
- **आर्किटेक्चर**: `io_uring` डायरेक्ट I/O द्वारा समर्थित अपेंड-ओनली लॉग-स्ट्रक्चर्ड मर्ज ट्री (LSM-Tree)।
- **विशेषताएं**: रीड हिट्स पर शून्य हीप मेमोरी आवंटन, फ्रैक्शनल कैस्केडिंग ब्लूम फिल्टर्स, और समवर्ती कॉम्पैक्शन पाइपलाइन।
- **प्रमुख मेट्रिक्स**: सब-मिलीसेकंड p99 लेटेंसी बनाए रखते हुए NVMe स्टोरेज पर प्रति सेकंड 420,000+ यादृच्छिक राइट्स निष्पादित करता है।

### 2. `meshpipe`
> Zig में लिखा गया मॉड्यूलर UDP/QUIC पैकेट मल्टीप्लेक्सर और टेलीमेट्री प्रोब।
- **आर्किटेक्चर**: एरिना एलोकेटर्स और कैशलाइन-अलाइन्ड रिंग बफ़र्स का उपयोग करने वाला इवेंट-संचालित वर्कर पूल।
- **विशेषताएं**: eBPF XDP हुक के माध्यम से इन-कर्नेल पैकेट फ़िल्टरिंग और यूजर-स्पेस SIMD चेकसमिंग।
- **उपयोग**: अस्थिर नेटवर्क पर एज क्लस्टर नोड्स के बीच रीयल-टाइम डिस्ट्रीब्यूटेड स्टेट सिंक्रोनाइज़ेशन।

### 3. `chronos-probe`
> Go और C (eBPF) में लिखा गया मिनिमलिस्ट कर्नेल टेलीमेट्री डेमन।
- **आर्किटेक्चर**: चल रहे बायनेरिज़ को बदले बिना डिस्क ब्लॉक लेयर और टीसीपी स्टैक में ट्रेसपॉइंट्स और kprobes को संलग्न करता है।
- **विशेषताएं**: पेज फ़ॉल्ट लेटेंसी और शेड्यूलर रनक्यू देरी के लिए शून्य-ओवरहेड प्रोमेथियस हिस्टोग्राम उत्सर्जित करता है।
- **उपयोग**: लेटेंसी-क्रिटिकल प्रोडक्शन माइक्रोसर्विसेज़ में टेल लेटेंसी स्पाइक्स का सटीक निदान।

### 4. `poly-dsp`
> आधुनिक C में निर्मित लाइटवेट पॉलीफोनिक वेवटेबल साउंड सिंथेसाइज़र इंजन।
- **आर्किटेक्चर**: SSE/AVX2 वेक्टराइज़्ड ऑसिलेटर्स और बैंडलिमिटेड BLEP सिंथेसिस के साथ लॉक-फ्री ऑडियो बफ़र रिंग।
- **विशेषताएं**: x86_64 पर 1.2% से कम सिंगल-कोर सीपीयू उपयोग के साथ 96kHz / 32-बिट फ़्लोट पर रीयल-टाइम प्रोसेसिंग।

## 📊 सिस्टम आर्किटेक्चर दृष्टिकोण

```
 [ क्लाइंट लेयर ]
        │  (QUIC / कस्टम बाइनरी प्रोटोकॉल)
        ▼
 [ eBPF XDP फ़िल्टर ] ─── (अर्ली ड्रॉप / फ़ास्ट पाथ)
        │
        ▼ (लिनक्स कर्नेल io_uring कम्प्लीशन कतार)
 [ रिंग बफ़र / SPSC कतार ] ── कैश-लाइन पैडेड
        │
   ┌────┴──────────────────────────┐
   ▼                               ▼
[ मेमोरी एरिना / ऑफ़-हीप ]   [ WAL डिस्क स्थिरता ]
   │ (SIMD इंडेक्स स्कैनिंग)       │ (डायरेक्ट I/O O_DIRECT)
   └───────────────┬───────────────┘
                   ▼
         [ स्थिर स्थिति क्वेरी ]
```

- **मैकेनिकल सिम्पथी**: L1/L2 डेटा कैश उपयोगिता को अधिकतम करने के लिए Array-of-Structures (AoS) के बजाय Structure-of-Arrays (SoA) लेआउट।
- **सख्त आवंटन अनुशासन**: हॉट लूप में मेमोरी एरिना और पूर्व-आवंटित रिंग बफ़र्स; कोई कचरा संग्रहकर्ता (GC) लेटेंसी स्पाइक्स नहीं।
- **विफलता पारदर्शिता**: स्पष्ट त्रुटि प्रबंधन, राइट-अहेड लॉगिंग के माध्यम से क्रैश रिकवरी, और संपूर्ण प्रॉपर्टी-आधारित परीक्षण।
