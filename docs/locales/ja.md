## 🚀 注目のオープンソースプロジェクト

自らアーキテクチャを設計し、保守している代表的なインフラ・ミドルウェア群です：

### 1. `vortex-kv`
> Rustで実装された超高速組み込みキー・バリューストレージエンジン。
- **アーキテクチャ**: `io_uring` Direct I/Oを活用した追加専用ログ構造化マージツリー（LSM-Tree）。
- **特徴**: リードキャッシュヒット時のヒープ割り当てゼロ、段階的ブルームフィルタ、非同期パイプライン化コンパクション。
- **性能指標**: NVMeストレージ環境において、1ミリ秒未満の決定論的p99レイテンシを維持しながら秒間42万回以上のランダムライトを処理。

### 2. `meshpipe`
> Zigで開発されたモジュール式UDP/QUICパケットマルチプレクサおよびテレメトリプローブ。
- **アーキテクチャ**: アリーナアロケータとキャッシュライン整列リングバッファを採用したイベント駆動型ワーカプール。
- **特徴**: eBPF XDPフックによるカーネル直下での早期パケット選別、ユーザランドでのSIMDチェックサム検証。
- **適用領域**: パケットロスが発生しやすいネットワーク条件下でのエッジクラスタノード間リアルタイム状態同期。

### 3. `chronos-probe`
> GoおよびC言語（eBPF）で構築された軽量カーネルテレメトリデーモン。
- **アーキテクチャ**: アプリケーションの再ビルドを不要とし、ブロック層およびTCPスタックにトレースポイントとkprobeを接続。
- **特徴**: ページフォールト遅延やスケジューラの実行キュー待機時間をオーバーヘッドなしでPrometheusヒストグラムとして出力。
- **適用領域**: 本番マイクロサービスにおけるテールレイテンシ（Tail Latency）の突発的急増の原因特定。

### 4. `poly-dsp`
> モダンC言語による軽量ポリフォニック・ウェーブテーブル音響合成エンジン。
- **アーキテクチャ**: ロックフリーオーディオリングバッファ、SSE/AVX2ベクトル化オシレータ、帯域制限付きBLEP波形生成。
- **特徴**: x86_64単一コアにおいてCPU負荷1.2%未満で96kHz / 32-bit floatリアルタイム音声を生成。

## 📊 システム設計の思想と構成図

```
 [ クライアント層 ]
        │  (QUIC / 独自バイナリプロトコル)
        ▼
 [ eBPF XDP フィルタ ] ─── (早期パケット破棄 / 高速ルーティング)
        │
        ▼ (Linuxカーネル io_uring 完了キュー)
 [ リングバッファ / SPSCキュー ] ── キャッシュラインパディング
        │
   ┌────┴──────────────────────────┐
   ▼                               ▼
[ メモリアリーナ / オフヒープ ]    [ WAL ディスク永続化 ]
   │ (SIMDインデックス走査)         │ (Direct I/O O_DIRECT)
   └───────────────┬───────────────┘
                   ▼
         [ 整合状態クエリエンジン ]
```

- **メカニカル・シンパシー**: L1/L2データキャッシュのヒット率を高めるため、AoS（構造体の配列）ではなくSoA（配列の構造体）レイアウトを徹底。
- **厳格なアロケーション管理**: クリティカルパス内ではメモリアリーナと事前割り当てリングバッファのみを用い、GC由来の遅延スパイクを完全排除。
- **障害に対する透明性**: 明示的なエラーハンドリング、WALによる確実なクラッシュ復旧、網羅的なプロパティベーステストの実施。
